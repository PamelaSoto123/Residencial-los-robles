# Residencial-los-robles
proyecto web para mejorar el control de pago de mantenimiento y la comunicación en residencial los robles
Residencial Los Robles
Descripción del proyecto
El proyecto consiste en desarrollar una plataforma web para Residencial Los Robles que facilite el control de las cuotas de mantenimiento y la comunicación entre la administración y los residentes.

Objetivo
Organizar la información de los pagos y mejorar el acceso de los residentes a los servicios e información del residencial.

Funciones principales
Inicio de sesión para residentes.
Consulta del historial de pagos.
Registro de pagos por parte de la administración.
Pago de cuotas en línea.
Avisos importantes.
Votaciones en línea.
Consulta del reglamento y contactos.
Sprint 1
HU-01: Inicio de sesión.
HU-02: Consulta de pagos.
HU-04: Registro de pagos.
Tecnologías previstas
React.
GitHub para guardar y documentar el código fuente.
